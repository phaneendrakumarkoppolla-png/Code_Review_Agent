# Security

Implemented:
- Helmet
- CORS
- body size limit
- schema validation
- centralized errors
- server-side API keys
- no secrets in frontend code

Before production:
- authentication
- authorization by team/project
- rate limiting
- audit logging
- secret management
- dependency scanning
- prompt/data privacy controls
- code execution sandbox if executing submitted code is ever added

Important: this application analyzes code as text. It does not execute submitted source code.
